# 220V AC to 12V/5V DC Power Supply

A PCB-based power supply designed to convert **220V AC mains voltage into 12V and 5V DC outputs** for powering low-voltage electronic circuits.

## Project Overview

This project includes the complete PCB design process, from schematic design and PCB routing to 3D visualization and final assembly.

## Features

* 220V AC input
* 12V DC output
* 5V DC output
* PCB designed using **KiCad**
* Custom PCB layout and routing
* 3D PCB model
* Final assembled power supply
* Suitable for low-voltage electronic circuits

## Applications

The 12V and 5V outputs can be used to power:

* Microcontrollers
* Sensors
* LEDs
* Relays
* Other low-voltage electronic circuits

## Safety

This project works with **220V AC mains voltage**. Proper insulation, isolation, fusing, grounding, and adequate PCB clearance are required. Mains-connected circuits should only be assembled and tested using appropriate electrical safety procedures.
